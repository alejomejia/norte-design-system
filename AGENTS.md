# Norte Design System

React 19 components and Tailwind v4 tokens for Norte, a fictional AI agent workspace, documented in Storybook. A
public showcase of how Alejandro Mejía builds a design system.

Before working, read:

- **`.agents/skills/norte-conventions/`** (linked from `.claude/skills/`): how code is organized and written. Apply it
  to every change and run its review checklist.
- **`CONTRIBUTING.md`:** branches (`dev` for work, `main` for releases), Conventional Commits checked by hooks,
  changesets and releases.
- **`docs/decisions/`:** why the stack is what it is. A changed decision gets a new record.

Rules:

- English only, in code, docs and commits. No AI attribution in commits.
- Work on `dev`; never commit to `main` (a hook blocks it). Commit only when asked.
- `pnpm check` passes before every push.
