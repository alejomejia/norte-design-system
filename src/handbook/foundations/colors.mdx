# Colors

Norte is neutrals and one blue. The blue marks what you can act on and what's selected; everything else is gray.
Green, amber and red only tell the state of something, like a run that succeeded, needs attention or failed. They
never decorate.

## Roles

Components read roles, never raw shades: `text-ink-muted` says what the text is for, and a brand change remaps the role
instead of editing every component. Each text role shows its contrast on the page, and `pnpm test` fails if a pair
drops below WCAG AA (4.5:1 for text, 3:1 for control borders and the focus ring).
