## Durations

Four lengths: fast for presses, base for most changes, slow for what enters the screen, slower for fills that sweep
across a control. The spring has a
length of its own: the time its curve takes to settle.

<Durations />

## Easing

Each change gets the curve of what it does. Hover a card to watch it. The spring is
[Motion](https://motion.dev)'s `spring(0.3, 0.3)` written as a CSS `linear()` curve, so a CSS transition and a Motion
animation settle the same way, with no JavaScript for the CSS one.
