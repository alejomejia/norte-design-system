## Reading a version

Versions follow [Semantic Versioning](https://semver.org/): `MAJOR.MINOR.PATCH`.

- **Patches** (fixes and small adjustments) raise the last number (`0.1.0` → `0.1.1`). Upgrade any time: nothing changes for your code.
- **New** raises the middle one (`0.1.1` → `0.2.0`): a new component, prop or token.
- **Breaking changes** need a change in your code to upgrade, and say which. While Norte is on `0.x`, they raise the
  middle number too, so read every `0.x` minor before upgrading. From `1.0.0` on, they raise the first.

Pin the version you use, read the notes, and upgrade when you're ready. How a change gets its note is in
[Contributing](https://github.com/alejomejia/norte-design-system/blob/dev/CONTRIBUTING.md#changesets).
