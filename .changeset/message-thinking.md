Add `Message`'s `thinkingEffect` (`breathe` by default, `shimmer` or `none`), `thinkingTimer`, a clock in tenths of a second after "Thinking", and `thinkingSince`. A message is no longer `aria-busy` while an agent writes, so live regions inside it (a streaming answer's paragraphs) are heard.
